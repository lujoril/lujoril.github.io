This is a template. Files in `_drafts/` are NOT published.

To publish an article:

1. Copy this file into the `_posts/` folder.
2. Rename it `YYYY-MM-DD-short-title.md`, for example `2026-12-01-scope-3-emissions.md`.
3. Write in Markdown, then commit and push. It appears on /articles/ within a minute or two.

## Formatting reminders

Use `##` for section headings, `**bold**`, `*italic*`, `[links](https://example.com)`,
and images with `![alt text](/your-image.png)`.
